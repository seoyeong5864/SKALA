# CNN 최적화 종합실습

**주제:** 철강 표면 결함 분류 모델 최적화  
**시간:** 13:30~17:00  
**구성:** 2인 1조  
**목표:** CNN 아키텍처를 이해하고, 주어진 데이터에 적합한 구조와 학습 방법을 코드로 실험하여 최적 모델을 찾는다.

## 수행 과제

1. 제공된 Baseline 노트북을 실행하고 결과를 확인한다.
2. Baseline 결과를 분석하여 개선할 문제를 정의한다.
3. 개선 목표를 정하고, 실험 가설에 따라 추가·변경 요소를 정한다.
4. Baseline에 한 요소씩 변경·추가하며 **3개 이상의 실험**을 수행한다.
5. 각 실험은 Validation 데이터로 평가하고, 최종 선택한 모델은 Test 데이터로 평가한다.

### 최적화 예시

- **아키텍처:** Layer 수, 채널 수, 커널 크기, Activation, BatchNorm
- **학습 방법:** Optimizer, Learning rate, Scheduler, Batch size
- **일반화:** Dropout, Weight decay, 데이터 증강
- **입력 데이터:** 이미지 크기, 정규화 방법

예시 외 방법도 사용할 수 있다. 누적 실험 또는 개별 실험을 선택하되, 변경 요소의 효과를 비교할 수 있도록 설계한다.
